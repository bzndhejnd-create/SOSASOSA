# OpportunityAI — Анализ локального рынка и возможностей бизнеса (Алматы)

Аналитическая геопространственная платформа для поиска перспективных мест открытия малого бизнеса на основе официальной статистики, реальных картографических данных и открытых реестров.

---

## 📌 Архитектура проекта и источники данных

Проект полностью исключает случайную генерацию координат, фиктивные компании и вымышленные рейтинги.

### 1. Географическая привязка и точные границы районов
* **Стандарт:** WGS84 GeoJSON (RFC 7946, координаты `[longitude, latitude]`).
* **Точные границы OpenStreetMap (все 8 районов Алматы):**
  * Алатауский район (OSM Relation: 3072216)
  * Алмалинский район (OSM Relation: 3072807)
  * Ауэзовский район (OSM Relation: 3072808)
  * Бостандыкский район (OSM Relation: 3390291)
  * Жетысуский район (OSM Relation: 3072130)
  * Медеуский район (OSM Relation: 3072217)
  * Наурызбайский район (OSM Relation: 5460063)
  * Турксибский район (OSM Relation: 3072001)
* **Пространственная привязка:** Алгоритм *Ray-Casting Point-in-Polygon (PIP)* с нативной поддержкой сложных контуров MultiPolygon и Polygon.

### 2. Официальная демографическая статистика
* **Источник:** Бюро национальной статистики Агентства по стратегическому планированию и реформам Республики Казахстан (stat.gov.kz).
* **Показатели по всем 8 районам г. Алматы (2024–2025):**
  * Фактическая численность постоянного населения (суммарно 2.28 млн чел.)
  * Урбанизированная и общая площадь (км²)
  * Плотность населения на км²
  * Среднемесячная номинальная заработная плата
  * Ориентиры арендных ставок коммерческой недвижимости

### 3. Реестр организаций, картография и Google Maps Platform
* **Схема данных организации:**
  ```json
  {
    "id": "gmaps_ChIJN1t_tDeuEmsRUsoyG83frY4",
    "name": "Presso Coffee",
    "category": "food",
    "address": "улица Жарокова, 180",
    "latitude": 43.2285,
    "longitude": 76.9185,
    "source": "Google Places API",
    "source_id": "gmaps/ChIJN1t_tDeuEmsRUsoyG83frY4",
    "last_verified_at": "2025-01-12",
    "confidence_status": "VERIFIED_GOOGLE"
  }
  ```
* **Провайдеры и картография:**
  * **Google Maps Картографический слой:** `mt{s}.google.com/vt/lyrs=m&x={x}&y={y}&z={z}` (Roadmap).
  * **Google Places API:** поиск действующих организаций в реальном времени с нативной дедупликацией.
  * Прямая интеграция с **Overpass API** (`api_provider.js`) с поддержкой зеркал и таймаутов.
  * Прямой переход к просмотру объекта в **Google Maps**.
* **Очистка данных:**
  * Автоматический фильтр выхода за пределы Bounding Box г. Алматы (`43.1200`–`43.3800` N, `76.7500`–`77.1000` E).
  * Дедупликация объектов в радиусе 35 метров по совпадению нормализованного названия.

### 4. Документированная формула скоринга
$$\text{Score} = \text{round}\left(100 \times \left(w_{dem} \cdot S_{dem} + w_{comp} \cdot S_{comp} + w_{infra} \cdot S_{infra} - w_{risk} \cdot R_{exp}\right)\right)$$

* $S_{dem}$ — индекс спроса на основе плотности населения района.
* $S_{comp}$ — индекс незаполненности рынка (соотношение числа конкурентов к целевой норме на 1000 жителей).
* $S_{infra}$ — индекс инфраструктуры и покупательной способности (средняя зарплата района).
* $R_{exp}$ — поправка на риск недостатка бюджета и опыта основателя.
* Веса факторов адаптируются под профиль бизнеса (общепит, образование, IT, медицина и др.).
* **Индекс достоверности (Confidence Index):** если выборка недостаточна, система явно понижает уверенность и выводит предупреждение.

## 🧪 Запуск автоматизированного тестирования

Для запуска 12 тестов аудита:
```bash
node tests/test_audit.js
```

Проверяются:
1. Порядок координат WGS84 в GeoJSON.
2. Локализация полигонов строго в пределах Алматы.
3. Точность Point-in-Polygon (Ray-Casting).
4. Наличие всех 8 районов Алматы по классификатору БНС РК и Википедии.
5. Отсечение точек вне города.
6. Дедупликация объектов в радиусе 35 метров.
7. Геодезическая точность формулы Haversine.
8. Воспроизводимость и факторный анализ скоринга.
9. Пересчет весов при смене категорий.
10. Честное снижение уверенности при малой выборке.
11. Отсутствие фиктивных данных при сбоях внешних API.
12. Подключение и методы интеграции с Google Maps Platform / Google Places API.
